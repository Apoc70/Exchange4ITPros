# Exchange Server Reporting

This repository section contains reporting scripts for Microsoft Exchange Server. The scripts collect information from on-premises Exchange environments and present it in formats suitable for operational review, troubleshooting, capacity planning, and documentation.

## Scripts

| Script | Purpose | Required Modules | Minimum Version |
|---|---|---|---|
| [Get-ExchangeEnvironmentReportv3](Get-ExchangeEnvironmentReportv3/README.md) | Generates a self-contained HTML overview of an Exchange environment | EMS | Exchange Server 2010 |

## Notes

- All scripts target modern Exchange Server versions unless stated otherwise in the script header.
- Refer to the `.NOTES` section of each script for details on target platform, required modules, and version history.
- Additional scripts and updates will be added to this folder over time.
